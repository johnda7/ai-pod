# Настройка Telegram бота

## 📋 Требования

- Node.js 18+
- Telegram Bot Token (уже предоставлен)

## 🚀 Быстрая установка

1. Перейдите в папку бота:
```bash
cd telegram-bot
```

2. Установите зависимости:
```bash
npm install
```

3. Создайте файл `.env`:
```bash
cp .env.example .env
```

4. Токен уже указан в коде, но можно добавить в `.env`:
```
TELEGRAM_BOT_TOKEN=REVOKED_TOKEN
```

5. Запустите бота:
```bash
npm start
```

Или в режиме разработки:
```bash
npm run dev
```

## ✅ Проверка работы

1. Найдите вашего бота в Telegram по токену
2. Отправьте команду `/start`
3. Бот должен ответить приветственным сообщением

## 🔧 Доступные команды

- `/start` - Начать работу
- `/help` - Справка
- `/profile` - Профиль пользователя
- `/tasks` - Список задач
- `/leaderboard` - Таблица лидеров
- `/katya` - Чат с AI-наставником
- `/week1`, `/week2`, `/week3` - Задачи по неделям

## 🔗 Интеграция с веб-приложением

Бот работает как дополнение к веб-приложению:
- Веб-приложение: https://johnda7.github.io/ai-pod/
- Бот предоставляет быстрый доступ к командам

## 📝 Расширение функциональности

Для добавления новых команд отредактируйте `index.js`:

```javascript
bot.onText(/\/mycommand/, (msg) => {
  const chatId = msg.chat.id;
  bot.sendMessage(chatId, 'Ответ на команду');
});
```

## 🐛 Решение проблем

**Бот не отвечает:**
- Проверьте токен в `.env` или в коде
- Убедитесь, что бот запущен (`npm start`)
- Проверьте интернет-соединение

**Ошибки при установке:**
- Убедитесь, что Node.js установлен: `node --version`
- Очистите кэш: `rm -rf node_modules && npm install`
